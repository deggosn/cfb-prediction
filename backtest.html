Threshold Backtest

Replays several past CFB seasons week-by-week — using only data that would have been available before each game was played — to check whether the app's current strong/lean thresholds for spread, total, and moneyline actually correspond to real historical edges, or were just reasonable-sounding guesses. Uses the exact same rating and blending logic as the live app, so results here should reflect what it would have done in the past.
